# Anatómiai mozgásfajták – Érthető összefoglaló

Az anatómiai mozgások leírása mindig az **anatómiai alapállásból** indul ki: egyenesen állsz, előre nézel, karjaid a tested mellett lógnak, és a **tenyereid előrefelé** néznek (hüvelykujj kifelé).

---

## 1. Alapmozgások (a legtöbb ízületnél előfordulnak)

| Mozgásfajta | Magyar jelentés | Mit jelent a gyakorlatban? (Hétköznapi példa) | Ellentéte |
| :--- | :--- | :--- | :--- |
| **Flexió** | Hajlítás | Két testrész közötti szög **csökken**. Pl. könyök behajlítása, térd behajlítása, törzs előrehajlítása, ujjak ökölbe szorítása. | Extensió |
| **Extensió** | Feszítés / nyújtás | Két testrész közötti szög **nő** (visszaegyenesedik). Pl. kar vagy láb kinyújtása, törzs kiegyenesítése. *(Ha az egyenesen túl hajlik hátra, az a **hyperextensió**.)* | Flexió |
| **Abdukció** | Távolítás | A végtag vagy ujj **távolodik** a test középvonalától. Pl. kar oldalemelése, láb oldalra emelése, ujjak szétterpesztése. | Addukció |
| **Addukció** | Közelítés | A végtag vagy ujj **közeledik** a test középvonalához. Pl. felemelt kar leengedése a törzs mellé, térdek összeszorítása, ujjak összezárása. | Abdukció |
| **Rotáció** | Forgatás | Egy csont a saját hossztengelye körül forog (mint egy csavarhúzó). Pl. fej „nem” intő elfordítása, vagy a felkar/comb elforgatása. | — |
| **Berotáció** *(belső / medialis rotáció)* | Befelé forgatás | A végtag elülső felszíne a test középvonala felé fordul. Pl. a kezedet a hasadra teszed, vagy a lábfejedet befelé csámpásítod csípőből. | Kirotáció |
| **Kirotáció** *(külső / lateralis rotáció)* | Kifelé forgatás | A végtag elülső felszíne kifelé fordul. Pl. kar kinyitása kifelé hajlított könyökkel, vagy lábfej kifelé fordítása (balett-alapállás). | Berotáció |
| **Circumdukció** | Körzés | Tölcsér alakú mozgás (a flexió + abdukció + extensió + addukció folyamatos egymásutánja). Pl. karkörzés. | — |
| **Lateralflexió** | Oldalra hajlítás | A fej, nyak vagy törzs oldalra döntése (fül a váll felé, vagy oldalra hajolás). | Ellenoldali lateralflexió |

## 2. Váll és vállöv speciális mozgásai

| Mozgásfajta | Magyar jelentés | Hétköznapi példa | Ellentéte |
| :--- | :--- | :--- | :--- |
| **Anteflexió** *(váll flexió)* | Előreemelés | A kar előrefelé történő felemelése (pl. nyújtózás előre). | Retroflexió |
| **Retroflexió** *(váll extensió)* | Hátrahúzás | A kar hátrafelé történő lendítése (pl. amikor hátranyúlsz a farzsebedhez). | Anteflexió |
| **Eleváció** | Emelés | A vállöv / lapocka felfelé húzása (vállvonogatás). | Depresszió |
| **Depresszió** | Süllyesztés | A felhúzott vállak leengedése, lenyomása. | Eleváció |
| **Protrakció** *(abdukció)* | Előrehúzás | A lapockák eltávolodnak a gerinctől, a vállak előreesnek (pl. ütés vége, előre görnyedés). | Retrakció |
| **Retrakció** *(addukció)* | Hátrahúzás | A lapockák összezárása a hát közepén („húzd ki magad!”, evezés). | Protrakció |
| **Lapocka kifelé / befelé rotációja** | Lapocka elfordulása | Ha a karodat vízszintes fölé emeled, a lapocka alsó csúcsa kifelé-előre fordul (**kifelé rotáció**); leengedéskor visszafordul (**befelé rotáció**). | Egymás ellentétei |

## 3. Alkar, csukló és kéz speciális mozgásai

| Mozgásfajta | Magyar jelentés | Hétköznapi példa | Ellentéte |
| :--- | :--- | :--- | :--- |
| **Szupináció** *(alkar)* | Hanyintás | Az alkar elforgatása úgy, hogy a **tenyér felfelé** nézzen (mintha levest tartanál benne). A radius és az ulna párhuzamos. | Pronáció |
| **Pronáció** *(alkar)* | Borintás | Az alkar elforgatása úgy, hogy a **tenyér lefelé** nézzen (pl. gépelés, labdapattogtatás). A radius keresztezi az ulnát. | Szupináció |
| **Palmarflexió** *(volarflexió)* | Tenyéri hajlítás | A csukló behajlítása a **tenyér** irányába (kézfej lefelé billen). | Dorsalflexió |
| **Dorsalflexió** *(csukló extensió)* | Kézháti hajlítás / feszítés | A csukló hátrafeszítése a **kézhát** irányába (pl. „állj!” kézjel, fekvőtámasz tartás). | Palmarflexió |
| **Radialabdukció** *(radialdeviáció)* | Hüvelykujj felé billentés | A kézfej oldalra hajlítása a **hüvelykujj** (radius) irányába. | Ulnarabdukció |
| **Ulnarabdukció** *(ulnardeviáció)* | Kisujj felé billentés | A kézfej oldalra hajlítása a **kisujj** (ulna) irányába. | Radialabdukció |
| **Oppozíció** | Szembehelyezés | A hüvelykujj szembe fordítása a többi ujjal (pl. csippentés, toll megfogása, „OK” jel). | Repozíció |
| **Repozíció** | Visszahelyezés | A hüvelykujj visszavitele a tenyér síkjába. | Oppozíció |

## 4. Boka és láb speciális mozgásai

| Mozgásfajta | Magyar jelentés | Hétköznapi példa | Ellentéte |
| :--- | :--- | :--- | :--- |
| **Dorsalflexió** *(boka)* | Lábfej felfelé húzása | A lábujjakat a sípcsont felé húzod (**sarkon járás**). | Plantarflexió |
| **Plantarflexió** *(boka)* | Talpi hajlítás / spiccelés | A lábfejet lefelé nyomod (**lábujjhegyre állás**, gázpedál nyomása). | Dorsalflexió |
| **Szupináció / Inverzió** *(láb)* | Befelé fordítás | A talp **befelé** fordul (egymás felé néz a két talp), a belső talpszél megemelkedik. *(A leggyakoribb bokaficam iránya!)* | Pronáció / Everzió |
| **Pronáció / Everzió** *(láb)* | Kifelé fordítás | A talp **kifelé** fordul, a külső talpszél megemelkedik (belső boka lesüllyed). | Szupináció / Inverzió |

## 5. Állkapocs, nyelv és szem speciális mozgásai

| Mozgásfajta | Magyar jelentés | Hétköznapi példa | Ellentéte |
| :--- | :--- | :--- | :--- |
| **Protrusio** *(protrakció)* | Előretolás | Az alsó állkapocs előretolása (harapáskor) vagy a nyelv kinyújtása. | Retrusio |
| **Retrusio** *(retrakció)* | Hátrahúzás | Az alsó állkapocs vagy a nyelv hátrahúzása. | Protrusio |
| **Eleváció / Depresszió** *(állkapocs)* | Zárás / nyitás | **Eleváció**: száj becsukása (harapás); **Depresszió**: száj kinyitása. | Egymás ellentétei |
| **Intorsio / Extorsio** *(szem)* | Szemgolyó tengely körüli forgása | **Intorsio**: a szem felső pólusa az orr felé fordul; **Extorsio**: a halánték felé fordul (fejdöntéskor tartja vízszintben a képet). | Egymás ellentétei |

## 6. Gyakori irány- és helyzetjelző szavak az izmoknál

Hogy az eredés–tapadás leírásokat is könnyen értsd:

- **Medialis** = test középvonala felé eső (belső) ↔ **Lateralis** = középvonaltól távolabbi (külső)
- **Anterior / Ventralis** = elülső ↔ **Posterior / Dorsalis** = hátsó
- **Superior / Cranialis** = felső (fej felé) ↔ **Inferior / Caudalis** = alsó (láb felé)
- **Proximalis** = törzshöz közelebbi (pl. váll) ↔ **Distalis** = törzstől távolabbi (pl. ujjak)
- **Palmaris / Volaris** = tenyéri oldal ↔ **Dorsalis** = kézháti / lábháti oldal
- **Plantaris** = talpi oldal
- **Superficialis** = felületes (bőrhöz közelebbi) ↔ **Profundus** = mély (csonthoz közelebbi)

## 7. Könnyű megjegyzési trükkök (puska)

1. **ABdukció vs. ADdukció**
   - **AD**dukció = hozzá**ad**od a testedhez (közelítés).
   - **AB**dukció = elrabolják („abduct”) a végtagod, tehát **el**távolodik a testedtől.
2. **Szupináció vs. Pronáció**
   - **SZUP**ináció = "**SOUP**" (leves) – úgy tartod a tenyered felfelé, mintha levest mernél bele.
   - **PRO**náció = leborítod, kiöntöd a levest (tenyér lefelé).
3. **Flexió vs. Extensió**
   - **Flex** = „flexelsz” (befeszíted a bicepszedet → behajlítod a könyököd).
   - **Ext**ensió = „extend” (kinyújtod, meghosszabbítod).
4. **Dorsalflexió vs. Plantarflexió (láb)**
   - **Plant**ar = a „planta” a talp (ahol a földet taposod) → talp irányába hajlítod (spiccelés).
   - **Dors**al = a „dorsum” a lábhát → lábhát felé húzod (pipálás / sarkon járás).
5. **Ujjak csontközti izmai: PAD és DAB**
   - **P**almaris / **P**lantaris interossei → **AD**dukció (**PAD**).
   - **D**orsalis interossei → **AB**dukció (**DAB**).
6. **Protrakció vs. Retrakció**
   - **Pro** = előre (pl. *pro*gresszió).
   - **Re** = hátra / vissza (pl. *re*tro).
